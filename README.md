# Prevent Notification Inbox Explosion

This example demonstrates how an event-driven system can overwhelm a user's inbox with excessive notifications, and how to prevent it. It contrasts a problematic approach where each event triggers an immediate email with a solution that batches multiple events into a single, summarized digest email, reducing notification volume and improving user experience.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
